Student Performance Analysis System Using Python
Project Overview

This project is a Python-based Student Performance Analysis System designed to manage student information and analyze academic performance.

It uses Python Lists, Dictionaries, the map() function, and Sets to organize student records, calculate total and average marks, identify unique values, and generate class performance summaries.

Features

1.Store student names, ages, addresses and subject marks.

2.Calculate individual student total marks.

3.Calculate individual student average marks.

4.Identify the overall class average.

5.Find the highest-performing student.

6.Identify unique student addresses and ages.

7.Generate student performance reports.

Python Concepts Used

1.Lists	Store multiple student records

2.Dictionaries	Store individual student information

3.map()	Calculate total and average marks

4.Sets	Identify unique ages and addresses
